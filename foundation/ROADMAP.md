# Roadmap

| Version | Focus and gate |
| --- | --- |
| 0.2.0 | Finish real desktop scene review and Windows x64 build; keep dev until mandatory gates pass |

| 0.8.0 | Expanded Studio project workflows, material/performance tools and plugin API policy |

| 1.0.0 | First stable public release after supported-platform and workflow acceptance |

Versions describe intended scope, not delivery dates or guarantees. Advanced work
must preserve the small upstream delta, licenses, measured results and old projects.
